# EduMark - Kalender Marketing Sekolah & Edukasi Indonesia (K-12)

Platform kalender pemasaran interaktif berbasis data siklus akademik sekolah (SD, SMP, SMA, Kampus), hari penting nasional, dan momentum belanja ritel di Indonesia.

---

## 🌟 Fitur Utama

- **Dual-View Mode**: 
  - **Tampilan Kalender Bulanan (Grid)**: Melihat kepadatan momen per tanggal dalam sebulan penuh dengan chip berwarna sesuai kategori.
  - **Kartu Inspirasi (Bento Cards)**: Kartu modular interaktif bergaya Bento/Notion lengkap dengan countdown (*H-X Hari*), tag audiens, dan trigger promosi.
- **Urgent Lead-Time Alert**: Indikator masa persiapan kampanye (H-30, H-14) agar pengiklan tidak terlambat beriklan sebelum hari-H.
- **Multi-Dimensi Filter**:
  - *Jenjang Pendidikan*: SD, SMP, SMA, Kampus
  - *Target Persona*: Siswa (Konsumen), Orang Tua (Pembayar Utama / Payer), Guru, Keluarga
  - *Kategori Produk*: ATK & Buku, Fashion & Seragam, F&B & Bekal Sehat, Bimbel & EdTech, Gadget & Elektronik, Wisata & Hiburan
- **Interactive Detail Drawer**:
  - Analisis *Payer vs Consumer* (mengapa Ibu yang bayar dan anak yang pakai).
  - 3 Ide sudut pandang promosi & kampanye.
  - Contoh copywriting iklan siap pakai dengan tombol *1-Click Copy*.
  - Tombol simpan langsung ke Google Calendar (*Add to Google Cal*).
  - Tombol salin rangkuman *Marketing Brief* lengkap.

## 🚀 Akses & Penggunaan

### 1. Langsung Lewat Browser (Online)
Kunjungi: **[https://whynunuu.github.io/EduMark/](https://whynunuu.github.io/EduMark/)**

### 2. Buka Langsung di Komputer (Offline/Lokal)
Cukup klik ganda file:
```
Buka_Kalender.bat
```
atau buka langsung file `index.html` di browser favorit Anda.

### 3. Jalankan Mode Full-Stack Next.js (Development)
```bash
npm install
npm run dev
```
Buka `http://localhost:3000` di browser.
